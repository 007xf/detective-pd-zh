# 公有领域侦探小说

本仓库收阅读指南中版权已经过期的长篇侦探小说。译文从公有领域原文独立写成，不沿用现有中文译本。已有中文译本的作品，同样从原文另译。

目前入库 10 种。文件名用三位编号加书名。

- [001 《诺丁山谜案》](001%20诺丁山谜案.epub)（*The Notting Hill Mystery*，查尔斯·费利克斯，1862–1865）
- [002 《血字的研究》](002%20血字的研究.epub)（*A Study in Scarlet*，阿瑟·柯南·道尔，1887）
- [003 《黑达德利罪案》](003%20黑达德利罪案.epub)（*The Crime at Black Dudley*，玛格丽·阿林厄姆，1929）
- [004 《弓区之谜》](004%20弓区之谜.epub)（*The Big Bow Mystery*，伊斯雷尔·赞格威尔，1892）
- [005 《巴斯克维尔的猎犬》](005%20巴斯克维尔的猎犬.epub)（*The Hound of the Baskervilles*，阿瑟·柯南·道尔，1902）
- [006 《谁的尸体》](006%20谁的尸体.epub)（*Whose Body?*，多萝西·L·塞耶斯，1923）
- [007 《毒巧克力命案》](007%20毒巧克力命案.epub)（*The Poisoned Chocolates Case*，安东尼·伯克莱，1929）
- [008 《特伦特最后一案》](008%20特伦特最后一案.epub)（*Trent's Last Case*，E. C. 本特利，1913）
- [009 《班森杀人事件》](009%20班森杀人事件.epub)（*The Benson Murder Case*，S. S. 范达因，1926）
- [010 《剧毒》](010%20剧毒.epub)（*Strong Poison*，多萝西·L·塞耶斯，1930）
